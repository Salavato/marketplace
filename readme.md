# Страховка

Сервис оформления страховых продуктов при покупке товаров на маркетплейсе. Покупатель в момент оформления заказа может подключить страховой продукт — страхование от повреждения, потери или возврата. Сервис фиксирует сделку, проводит транзакцию и хранит историю всех оформленных страховок.

---

## Целевая аудитория

Физические лица — покупатели товаров на маркетплейсе.

### Портреты клиентов

| Портрет | Описание |
|---|---|
| Осторожный покупатель | Приобретает технику или дорогостоящие товары, хочет защититься от поломки или потери при доставке |
| Частый покупатель | Регулярно заказывает товары, ценит удобство оформления страховки в один клик прямо в корзине |
| Новый пользователь | Впервые покупает на маркетплейсе, не уверен в надёжности доставки, рассматривает страховку как дополнительную гарантию |

---

## MVP

Реализовать возможность оформления страховки физическим лицом и обеспечить хранение всех сделок в базе данных. Реализация в формате REST API (бэкенд), без фронтенд-интерфейса.

---

## Сущности

**InsuranceProduct (Страховой продукт)** — справочник доступных страховых программ с названием, описанием условий и стоимостью.
Методы: сами продукты будут заполняться админом напрямую в БД через скрипт миграции.

**Deal (Сделка)** — факт оформления страхового продукта покупателем по конкретному заказу.
Методы: Создание сделки, отмена сделки

---

## Архитектура

![Архитектура](architecture.png)

Компоненты:

- **Клиент** — покупатель отправляет запросы через REST API
- **REST API** — точка входа, маршрутизация запросов
- **Business Logic** — обработка бизнес-правил оформления страховки
- **PostgreSQL** — хранение сущностей: InsuranceProduct, Deal, DealStatus, Transaction
- **Payment Gateway** — внешний сервис проведения транзакций
